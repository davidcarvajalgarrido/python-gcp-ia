# Proyecto Allinator (Ejercicios)

## Fase 1: Marco Polo con Cloud Engine

![marco-polo-stewie](marco-polo-stewie.jpg)

1. Hacer [este lab](https://www.skills.google/focuses/2794?catalog_rank=%7B%22rank%22%3A1%2C%22num_filters%22%3A0%2C%22has_search%22%3Atrue%7D&parent=catalog&search_id=83389153) de Google Skills.
2. Instalar gcloud en la máquina de desarrollo.
3. Crear una instancia de Cloud Engine via Consola en el navegador web.
4. Modificar el almacenamiento via gcloud.
5. Entrar en la máquina via SSH e instalar: git, node y python.
6. Crear una API REST (con Express o FastAPI) en la máquina virtual con el siguiente endpoint:
  - GET /marco - Response "Polo"
7. Lanzar una petición al endpoint para ver que responde adecuadamente.
