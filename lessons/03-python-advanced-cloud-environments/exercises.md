# Lección 3 — Ejercicios

## Ejercicio 1: Implementa una clase con herencia múltiple

1. Crea dos clases base con un método cada una.
2. Implementa una clase derivada que herede de ambas clases base.
3. Define un método en la clase derivada que utilice métodos de las clases base.

## Ejercicio 2: Usa mypy para verificar tipos en un script

1. Escribe un script de Python con funciones que utilicen anotaciones de tipo.
2. Instala mypy si no lo tienes ya instalado.
3. Ejecuta mypy en el script para verificar los tipos.

## Ejercicio 3: Crea un generador para números pares

1. Define un generador que devuelva números pares hasta un máximo dado.
2. Itera sobre el generador e imprime los números generados.

## Ejercicio 4: Implementa un iterador personalizado

1. Escribe una clase que implemente el protocolo de iterador en Python.
2. Asegúrate de que tu iterador pueda ser utilizado en un bucle for.

## Ejercicio 5: Refactoriza una función utilizando un decorador

1. Escribe una función simple que imprima un mensaje.
2. Crea un decorador que modifique el comportamiento de la función, por ejemplo, añadiendo un mensaje antes y después de su ejecución.
3. Aplica el decorador a la función e imprime el resultado.
