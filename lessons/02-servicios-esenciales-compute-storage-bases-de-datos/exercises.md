# Lección 2 — Ejercicios

## Ejercicio 1: Crear una máquina virtual en Compute Engine

1. Accede a la consola de Google Cloud Platform.
2. Navega a Compute Engine y crea una nueva instancia con las configuraciones predeterminadas.
3. Verifica que la instancia esté en ejecución y que puedas acceder a ella vía SSH.

## Ejercicio 2: Configurar un bucket en Cloud Storage

1. Desde la consola de GCP, accede a Cloud Storage.
2. Crea un nuevo bucket y establece la clase de almacenamiento en 'nearline'.
3. Sube un archivo de prueba al bucket y verifica su accesibilidad.

## Ejercicio 3: Conectar una aplicación Python a Cloud SQL

1. Crea una base de datos en Cloud SQL utilizando MySQL.
2. Configura las credenciales necesarias para la conexión.
3. Escribe un script en Python que se conecte a la base de datos y realice una consulta simple.

## Ejercicio 4: Desplegar un contenedor en Cloud Run

1. Prepara una imagen de contenedor Docker con una aplicación simple.
2. Sube la imagen a Google Container Registry.
3. Despliega el contenedor en Cloud Run y verifica su funcionamiento.

## Ejercicio 5: Usar Firestore para almacenar y recuperar datos

1. Crea una colección en Firestore desde la consola de GCP.
2. Escribe un script en Python que almacene un documento en la colección.
3. Modifica el script para recuperar y mostrar el documento almacenado.
