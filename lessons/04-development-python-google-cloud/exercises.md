# Lección 4 — Ejercicios

## Ejercicio 1: Conectar una aplicación Python con Google Cloud Storage

1. Configura una cuenta de servicio en GCP y descarga el archivo de clave JSON.
2. Instala la librería cliente de Google Cloud en tu entorno Python.
3. Escribe un script que se autentique con GCP y liste los archivos de un bucket de Cloud Storage.

## Ejercicio 2: Crear una función en Google Cloud Functions

1. Accede a la consola de Google Cloud y navega a Cloud Functions.
2. Crea una nueva función que se active mediante HTTP y devuelva un mensaje de saludo.
3. Despliega la función y prueba su funcionamiento a través de un navegador o herramienta HTTP.

## Ejercicio 3: Configurar un flujo de trabajo con Pub/Sub

1. Crea un tópico en Pub/Sub desde la consola de GCP.
2. Escribe un script Python que publique mensajes en el tópico.
3. Desarrolla una función en Cloud Functions que procese los mensajes publicados y los registre.

## Ejercicio 4: Analizar logs de Cloud Functions usando AI

1. Accede a los registros de tus Cloud Functions a través de Cloud Logging.
2. Configura un análisis básico para identificar patrones de error.
3. Utiliza herramientas de IA para sugerir mejoras en el rendimiento de tus funciones.

## Ejercicio 5: Diseñar un microservicio serverless en GCP

1. Planifica un flujo que integre Cloud Functions, Pub/Sub y Cloud Storage.
2. Implementa y despliega los componentes del microservicio en GCP.
3. Prueba el flujo completo asegurando que los componentes se comunican correctamente.
